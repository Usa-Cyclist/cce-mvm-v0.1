# CCE-MVM v0.1 author-confirmed release staging

Status: local staging only; not authorized for publication or external sharing

This directory holds an author-confirmed, sanitized source candidate together
with the exact citation and license materials planned for a future public
release. It remains deliberately non-publishable: the repository URL, clean
commit, CI run, release tag, fixed archive, public-release authorization, and
external readback do not yet exist.

The final license files are kept under `release-materials/`, not at the future
repository root. `DRAFT-NOT-FOR-PUBLICATION.md` remains present. These two
features prevent this staging directory from being mistaken for the public
release.

The candidate contains synthetic experiments only. It contains no patient or
human-participant data, institutional review material, formative feedback, or
future H1c-R material.

CCE-MVM v0.1 is a research explanation model. It is not a clinical decision
tool, capacity assessment, legal determination, medical device, or validated
measure of personal sovereignty.

Before publication, the staged materials must be transferred into a separate
clean repository, tested by the declared CI matrix, bound to a clean commit,
and passed through the final fail-closed release verifier after the author gives
separate publication authorization.
