# H1・H2 観察誤差に対する頑健性確認 v0.1

作成日: 2026-08-01  
状態: CCE-MVM v0.1のシード固定合成実験  
データ: すべて説明用の合成値

## 1. 目的

H1aとH2の初期結果が、誤差のない1回の実験だけに依存していないかを確認する。

各観察へ平均0、標準偏差0.10の正規分布ノイズを加え、100個の固定乱数シードで繰り返す。同じシードでは、全学習率に同じ観察系列を使う。したがって900行は独立900反復ではなく、独立なノイズ系列100本を9条件へ対応づけた共通乱数比較である。

## 2. やさしい説明

同じ体温を測っても、測り方や機器によって少し違う数字が出る。今回の観察誤差は、このような「毎回少し違う」を人工的に加える操作である。

乱数シードは、乱数の並びに付ける番号である。同じシードなら同じ誤差が再現される。

## 3. 条件

| 項目 | 設定 |
|---|---|
| ノイズ | 正規分布 |
| 平均 | 0 |
| 標準偏差 | 0.10 |
| 観察値の範囲 | -1から+1で打ち切り |
| シード | 41000から41099 |
| 繰り返し | 各条件100回 |
| H1aの学習率 | 0.05, 0.20, 0.50, 0.80 |
| H2の学習率 | 0.05, 0.20, 0.50, 0.80, 1.00 |
| 条件行数 | 100系列×9条件＝900行 |
| 独立な乱数系列 | 100本 |

標準偏差0.10は実データから推定した値ではない。最小モデルの動作確認用の暫定値である。

## 4. 集計方法

各条件について次を保存する。

- 100回それぞれの結果
- 中央値
- 下側5%点
- 上側95%点

5〜95%範囲は信頼区間ではない。今回の100シードで得られたばらつきの記述である。

## 5. 判定規則

### H1a

観察誤差を加えても、学習率が高くなるほど累積本人モデル誤差の中央値が小さくなるかを見る。

### H2

観察誤差を加えても、学習率が高くなるほど一時変化による最大逸脱の中央値が大きくなるかを見る。回復時間はこのノイズ実験の測定項目に含めず、H2bをノイズ条件で確認済みとは扱わない。

一致ステップ数は、現在の固定設定で最近傍選択肢が一意になる範囲の診断である。同距離候補が生じる一般設定の決定規則として解釈しない。

## 6. 結果

### H1a：変化後の累積本人モデル誤差

| 学習率 | 中央値 | 5〜95%範囲 |
|---:|---:|---:|
| 0.05 | 19.509 | 19.103〜19.857 |
| 0.20 | 6.378 | 5.836〜6.905 |
| 0.50 | 2.209 | 1.859〜2.638 |
| 0.80 | 1.532 | 1.166〜1.918 |

今回の100シードすべてをまとめても、学習率が高くなるほど累積誤差の中央値は小さくなった。

### H2：一時変化中の最大逸脱

| 学習率 | 中央値 | 5〜95%範囲 |
|---:|---:|---:|
| 0.05 | 0.153 | 0.134〜0.178 |
| 0.20 | 0.572 | 0.517〜0.631 |
| 0.50 | 1.201 | 1.107〜1.294 |
| 0.80 | 1.542 | 1.398〜1.666 |
| 1.00 | 1.658 | 1.534〜1.761 |

今回の100シードすべてをまとめても、学習率が高くなるほど最大逸脱の中央値は大きくなった。

### 判定

- H1aの事前判定規則を満たした。
- H2aの事前判定規則を満たした。H2bの回復時間は未測定である。
- 選択した正規ノイズ、標準偏差0.10、100シードの範囲で傾向が維持された。

これは選んだ分布と100本の乱数系列に依存する合成シミュレーション結果であり、更新式から必ず出る解析的証明でも、現実の観察誤差に対する外的妥当性でもない。別の誤差分布、欠測、遅延、系統的偏りでも同じ結果になるとは限らない。

## 7. 再現方法

ワークスペースのルートで実行する。

```bash
python3 -B -m cce.simulation.noise_robustness \
  --output-dir ../cce-h1-h2-noise-reproduction
```

保存済み正本 `results/h1_h2_noise_v0.1/` を再現出力で上書きしない。

テスト:

```bash
python3 -B -m unittest -v cce.simulation.test_noise_robustness
```

## 8. 注意

- 合成ノイズへの頑健性であり、現実の観察誤差に対する妥当性ではない。
- 正規分布という仮定は暫定である。
- ノイズを加えても、本人意思を「真値」として完全に観察できるという問題は残る。
- 次版では欠測、偏りのある誤差、観察の遅延を別々に扱う。
