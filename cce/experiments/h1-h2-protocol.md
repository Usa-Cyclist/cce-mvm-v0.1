# H1・H2 合成実験プロトコル v0.1

作成日: 2026-08-01  
状態: CCE-MVM v0.1の決定論的な初期実験  
データ: すべて説明用の合成値

## 1. 今回検証できる範囲

現時点のコードには、AIの提案が本人の応答をどれだけ変えるかという「影響モデル」がまだない。

そのため、H1を二つに分ける。

- **H1a（今回検証）**: 学習率が低いほど、本人意思が変わった後もAI本人モデルと提案が過去へ固定される。
- **H1b（後で検証）**: AIの影響が強いほど、その固定された提案が最終決定の不一致を増やす。

H1bを先に実装すると、根拠のない「AI影響力」の式を置くことになるため、v0.1では行わない。

H2は次の形で検証する。

- **H2a（今回検証）**: 学習率が高いほど、一時的な反対方向の観察へ大きく追随し、本人モデルと提案の変動が大きくなる。
- **H2b（固定条件でのみ確認）**: ショック長2、回復許容誤差0.10の決定論的条件では、学習率が高いほど通常観察へ戻った後の回復ステップが短くなる。

## 2. 共通式

\[
M_{t+1}=(1-\lambda)M_t+\lambda O_t
\]

- \(M_t\): その時点のAI本人モデル
- \(O_t\): 今回の観察
- \(\lambda\): 学習率

今回はリスクによる差引きを0にして、学習率だけの効果を分離する。

## 3. H1a：過去本人像への固定

### 条件

| 項目 | 値 |
|---|---:|
| 全期間 | 30ステップ |
| 意思が変化する時点 | \(t=10\) |
| 変化前の本人意思 | -0.8 |
| 変化後の本人意思 | +0.8 |
| AI本人モデルの初期値 | -0.8 |
| 学習率 | 0.05, 0.20, 0.50, 0.80 |
| 回復とみなす誤差 | 0.10以下 |
| 観察誤差・乱数 | なし |

### 測るもの

- 変化後の本人モデル誤差の累積
- 最も大きい誤差
- AI提案が本人の現在方向と異なるステップ数
- 誤差0.10以下へ戻るまでのステップ数
- 最終時点の誤差

### 実行前に固定した予測と分類

学習率が低いほど、累積誤差、提案不一致期間、回復時間が大きくなる。

誤差なしの一定観察における本人モデル誤差の縮小率は、更新式から代数的に導かれる。したがってH1aの主要な単調方向は、人間について新たに発見した経験則ではなく、式・実装・保存結果の一致を調べる構造的検査である。最近傍選択肢による不一致期間と有限期間内の回復は、選択肢配置と閾値にも依存する。

## 4. H2：一時的状態への過剰追随

### 条件

| 項目 | 値 |
|---|---:|
| 全期間 | 25ステップ |
| 比較的安定した本人価値 | +0.8 |
| 通常の観察 | +0.8 |
| 一時的な反対方向の観察 | -0.8 |
| 一時変化の期間 | \(t=10,11\) の2ステップ |
| AI本人モデルの初期値 | +0.8 |
| 学習率 | 0.05, 0.20, 0.50, 0.80, 1.00 |
| 回復とみなす誤差 | 0.10以下 |
| 乱数 | なし |

### 測るもの

- 安定した本人価値からの最大逸脱
- 全期間の累積誤差
- 基準と異なる提案を出したステップ数
- 通常観察へ戻った後の回復時間

### 実行前に固定した予測と分類

学習率が高いほど、一時変化中の最大逸脱は大きくなる。通常観察へ戻った後の回復時間は、今回固定したショック長2・許容誤差0.10の範囲で比較する。許容帯を一度も超えない条件は「0ステップで回復」とせず、回復時間を未定義として区別する。

このため「学習率は高いほどよい」「低いほどよい」とは予測しない。

固定ショックに対する最大逸脱の方向は更新式から導かれる構造的性質である。一方、回復ステップはショック長、許容誤差、有限の観察期間、離散ステップに依存するため、構造的一般則として扱わない。

## 5. 反証・見直し条件

### H1a

学習率を下げても、累積誤差や提案不一致期間が増えない場合、H1aまたは測定方法を見直す。

### H2

学習率を上げても一時変化中の最大逸脱が増えない場合、H2aまたは一時変化の定義を見直す。H2bはショック長または許容誤差を変えると順序が変わり得るため、固定条件外へ一般化しない。

現在の固定系列では、参照値と提案値の最近傍選択肢は各時点で一意である。時系列モジュールの一致ステップ数を、同距離候補が生じる別設定へ一般化しない。同距離を含む一般時系列の扱いはv0.2候補である。

期待した単調関係が出るように、実験後に条件を変更してはならない。条件を変える場合は新しい版として記録する。

## 6. 読み方の注意

- この実験は式が設定どおり動くかを見る単体実験に近い。
- 合成データで仮説が支持されても、現実の人間やケアで正しいとは証明できない。
- 学習率は人間の理解やAI学習の全体を表すものではない。
- H2の反対方向の観察を、本人の意思が「本物ではない」と判定するために使わない。
- 本人価値と一時的状態を区別する方法は、当事者参加と実証研究を伴う別課題である。

## 7. 初期結果

### H1a

| 学習率 | 累積誤差 | 提案不一致ステップ | 誤差0.10以下への回復 |
|---:|---:|---:|---:|
| 0.05 | 19.502 | 20 | 30ステップ内に回復せず |
| 0.20 | 6.326 | 7 | 13ステップ |
| 0.50 | 1.600 | 2 | 4ステップ |
| 0.80 | 0.400 | 1 | 2ステップ |

学習率が低いほど、本人意思の変化後に本人モデルと提案が過去へ長く残った。これは更新式から導かれる方向と実装・保存結果が一致したことを示す。

### H2

| 学習率 | 最大逸脱 | 提案不一致ステップ | 通常観察へ戻った後の回復 |
|---:|---:|---:|---:|
| 0.05 | 0.156 | 0 | 9ステップ |
| 0.20 | 0.576 | 4 | 8ステップ |
| 0.50 | 1.200 | 3 | 4ステップ |
| 0.80 | 1.536 | 3 | 2ステップ |
| 1.00 | 1.600 | 2 | 1ステップ |

学習率が高いほど、一時変化中の最大逸脱が大きくなった。固定したショック長2・許容誤差0.10では、通常観察へ戻った後の回復ステップも短くなった。これは条件付き結果であり、ショック長や許容誤差を変えた一般則ではない。提案不一致ステップ数は単調には増えなかったため、「高い学習率ほど不一致期間が長い」とは結論しない。

これらは設定した更新式が事前予測どおり動いたことを示す。H1aやH2が現実のケアで妥当だと証明した結果ではない。

### H2回復判定の許容誤差感度

同じ軌道を用い、回復とみなす許容誤差だけを変えると次のようになる。括弧内は学習率0.05、0.20、0.50、0.80、1.00の順である。

| 許容誤差 | 回復ステップまたは状態 |
|---:|---|
| 0.05 | 期間内未回復、11、5、3、1 |
| 0.10 | 9、8、4、2、1 |
| 0.16 | 許容帯を超えず、6、3、2、1 |

したがってH2bは許容誤差0.10に固定した離散的結果である。CSVでは空欄だけで二つの意味を兼ねず、`recovery_status` を `recovered`、`not_recovered_within_horizon`、`no_qualifying_excursion` のいずれかとして併記する。

## 8. 再現方法

ワークスペースのルートで実行する。

```bash
python3 -B -m cce.simulation.h1_h2_experiments \
  --output-dir ../cce-h1-h2-reproduction
```

保存済み正本 `results/h1_h2_v0.1/` を再現出力で上書きしない。

設定:

- `config/h1_h2_v0.1.json`

出力:

- `results/h1_h2_v0.1/summary.csv`
- `results/h1_h2_v0.1/trajectories.csv`
- `results/h1_h2_v0.1/metadata.json`

テスト:

```bash
python3 -B -m unittest -v cce.simulation.test_h1_h2_experiments
```
