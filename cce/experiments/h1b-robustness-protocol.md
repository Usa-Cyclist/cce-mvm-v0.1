# H1b 初期応答・選択肢頑健性実験プロトコル v0.1

作成日: 2026-08-01  
状態: 実行前に内部固定し実装・実行済み（外部レジストリ未登録）
データ: すべて説明用の合成値

## 1. 目的

H1b基準実験の段差が、本人の初期応答 \(B=+1\) と選択肢 \(\{-1,0,+1\}\) だけに依存していないかを確認する。条件と予測は実行前に内部固定したが、外部レジストリには登録していない。

式、決定規則、権利ゲートは変更せず、次の二点だけを別々に変える。

- **R1 初期応答感度:** 本人の初期応答 \(B\) を変える。
- **R2 選択肢感度:** 選択肢の数と間隔を変える。

## 2. 初心者向けの見方

連続した応答 \(Y\) を、用意された選択肢のうち最も近いものへ移すため、最終決定は階段状になる。

- 出発点 \(B\) を変えると、階段を下り始める位置が動く可能性がある。
- 選択肢を細かくすると、同じ端から端への変化が小さな段差へ分かれる。
- これは選択肢を多くすれば必ず良いという価値判断ではない。式と選択肢配置の関係だけを確認する。

## 3. 変更しないもの

提案後応答はH1b基準実験と同じ式を使う。

\[
Y(a)=(1-a)B+aQ
\]

応答効果と決定効果も変更しない。

\[
I_Y^A=\frac{|Y(a)-Y(0)|}{2},
\qquad
I_D^A=\frac{|D(a)-D(0)|}{2}
\]

共通条件:

| 項目 | 固定内容 |
|---|---|
| 結合度 \(a\) | 0.0から1.0まで0.1刻みの11水準 |
| AIの決定権 | なし |
| 有効な委任 | なし |
| 権利ゲート | 6項目すべて適合 |
| 同距離規則 | 一つへ自動決定せず保留 |
| 乱数 | 使わない |

## 4. R1 初期応答感度

選択肢を \(\{-1,0,+1\}\) に固定し、初期応答を次の4水準へ変える。

\[
B\in\{+1,+0.75,-0.75,-1\}
\]

AI提案は各初期応答の正反対 \(Q=-B\) とする。

\[
4\text{初期応答}\times11\text{結合度}=44\text{条件}
\]

### 4.1 事前予測

\[
Y(a)=B(1-2a)
\]

\[
I_Y^A=a|B|
\]

したがって、\(|B|=1\) では応答効果が \(a\) と一致し、\(|B|=0.75\) では \(0.75a\) になる。

| \(|B|\) | 決定効果0 | 決定効果0.5 | 決定効果1 |
|---:|---|---|---|
| 1.00 | \(a=0.0\)〜0.2 | \(a=0.3\)〜0.7 | \(a=0.8\)〜1.0 |
| 0.75 | \(a=0.0\)〜0.1 | \(a=0.2\)〜0.8 | \(a=0.9\)〜1.0 |

正負を反転した \(+B\) と \(-B\) では、最終決定の符号は反転するが、応答効果と決定効果は同じになると予測する。

## 5. R2 選択肢感度

初期応答 \(B=+1\)、AI提案 \(Q=-1\) を固定し、研究上の環境条件として次の3つの選択肢集合を比較する。

| 条件 | 選択肢 | 役割 |
|---|---|---|
| endpoints_2 | \(-1,+1\) | 中間選択肢がない場合 |
| baseline_3 | \(-1,0,+1\) | H1b基準実験 |
| dense_5 | \(-1,-0.5,0,+0.5,+1\) | 中間選択肢が細かい場合 |

\[
3\text{選択肢集合}\times11\text{結合度}=33\text{条件}
\]

### 5.1 事前予測

| 選択肢集合 | 決定効果の予測 |
|---|---|
| endpoints_2 | 0、\(a=0.5\)の保留、1 |
| baseline_3 | 0、0.5、1 |
| dense_5 | 0、0.25、0.5、0.75、1 |

すべての集合で応答 \(Y=1-2a\) と応答効果 \(I_Y^A=a\) は同じと予測する。違うのは連続値をどの選択肢へ移すかである。

この比較では、選択肢集合は研究者が実験条件として最初から定める。AIが選択肢を途中で削除するH1b-2の選択肢喪失とは区別し、権利保護の優劣を主張しない。

## 6. 合格条件

### R1

- 44条件を重複なく出力する。
- 全条件で \(I_Y^A=a|B|\) と一致する。
- \(|B|=1\) と0.75で、事前固定した決定効果の段差と一致する。
- \(+B\) と \(-B\) の効果が対称になる。
- 権利違反または無効結果を作らない。

### R2

- 33条件を重複なく出力する。
- 3集合すべてで応答 \(Y\) と応答効果が一致する。
- 各集合の決定効果列が設定ファイルの事前系列と一致する。
- endpoints_2の \(a=0.5\) だけを同距離として保留する。
- 選択肢集合の違いをAIによる選択肢削除と記録しない。

## 7. 反証・見直し条件

- R1で応答効果が \(a|B|\) と一致しない。
- 正負を反転した条件で効果が非対称になる。
- R2で選択肢集合を変えると応答 \(Y\) まで変わる。
- 事前系列と異なる決定効果が出る。
- 同距離を一案へ自動決定する。
- 権利ゲート違反を生じさせる。

一つでも起きた場合、結果に合わせて予測を変更せず、式、丸め、最近傍規則、設定読込のどこに原因があるかを記録する。

## 8. 解釈上の注意

- これは数式と選択肢配置に対する構造的な頑健性確認である。
- 初期応答0.75は実測尺度から得た値ではない。
- 選択肢の数と本人主権の高低を直接結びつけない。
- 人間の反応、現実のAI影響、望ましい選択肢数は主張しない。
- R1とR2を同時に変えないため、二要因の相互作用はまだ扱わない。
- `ai_option_loss_structural_constant`、`rights_violation_structural_constant`、`analysis_row_valid` はこの頑健性設計で固定した構造定数であり、77条件を通して経験的に検出した成果とは数えない。`analysis_row_valid` は権利的・臨床的妥当性を意味しない。
- `person_response` の `modify/defer` は連続式の最近傍結果を決定規則へ渡すための分析上の代入であり、実在する本人の応答ではない。全行に分析代入の来歴を保存し、同距離時だけ `pause_source=discretization_tie` とする。
- R1で初期応答0.75を使う条件は、基準応答が選択肢そのものではないため、H1b基準実験で同値だった `decision_effect` と `decision_mismatch` の分離を確認する役割を持つ。

## 9. 実行結果

当初、実行前に内部固定した数値条件を変更せず、R1の44条件とR2の33条件、合計77条件を実行した。外部レジストリへの登録は行っていない。2026-08-30には来歴専用フィールドだけを設定ファイルへ追加し、数値条件を変えずに再生成した。現在の設定SHAは安全是正版を識別するが、当初の内部固定時点を第三者タイムスタンプで証明するものではない。

| 実験 | 実行数 | 事前予測との一致 | 結果 |
|---|---:|---:|---|
| R1 初期応答感度 | 44 | 44/44 | \(I_Y^A=a|B|\)、決定効果の段差、正負の対称性が一致 |
| R2 選択肢感度 | 33 | 33/33 | 2・3・5選択肢の事前系列と同距離保留が一致 |
| 合計 | 77 | 77/77 | 式と離散決定系列が一致。分析対象・権利違反の列は設計上の定数 |

### 9.1 R1の結果

| 初期応答の大きさ | 実際の決定効果列 \(a=0.0\)〜1.0 |
|---:|---|
| \(|B|=1.00\) | 0, 0, 0, 0.5, 0.5, 0.5, 0.5, 0.5, 1, 1, 1 |
| \(|B|=0.75\) | 0, 0, 0.5, 0.5, 0.5, 0.5, 0.5, 0.5, 0.5, 1, 1 |

\(|B|=0.75\)では、初期応答が中央の選択肢0に近いため、最初の段差が \(a=0.3\) から0.2へ早まり、反対端への完全な移動は \(a=0.8\) から0.9へ遅れた。正負を反転した条件では効果列が同一になった。

### 9.2 R2の結果

| 選択肢集合 | 実際の決定効果列 \(a=0.0\)〜1.0 |
|---|---|
| 2選択肢 | 0, 0, 0, 0, 0, 保留, 1, 1, 1, 1, 1 |
| 3選択肢 | 0, 0, 0, 0.5, 0.5, 0.5, 0.5, 0.5, 1, 1, 1 |
| 5選択肢 | 0, 0, 0.25, 0.25, 0.5, 0.5, 0.5, 0.75, 0.75, 1, 1 |

3集合で提案後応答と応答効果は同一だった。選択肢が細かいほど、同じ連続応答を小さな決定段差へ移した。2選択肢の \(a=0.5\) だけが同距離となり、予定どおり保留された。

この結果は、H1bの「連続応答と離散決定を分ける」という構造が、今回の初期値と選択肢配置の範囲で維持されたことを示す。人間の反応や望ましい選択肢数を示す結果ではない。
