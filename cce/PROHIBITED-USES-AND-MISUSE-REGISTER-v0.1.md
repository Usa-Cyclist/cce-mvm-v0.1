# CCE-MVM v0.1 禁止用途・誤用登録簿

版: v0.1  
作成日: 2026-08-30  
対象: CCE-MVM v0.1の仕様、コード、合成結果、説明図、再現パッケージ

## 1. 位置づけ

CCE-MVM v0.1は、ケア生態系における本人モデルの更新、AI提案の影響、決定手続き、権利条件を分けて考えるための説明用数理モデルである。実在する人のデータで妥当性を確認した臨床尺度、意思決定支援システム、法的判定器ではない。

次の用途には使用しない。将来の版で一部を研究対象にする場合も、新しい版、倫理・法務確認、人間による評価、停止条件を別に必要とする。

## 2. 禁止用途と対抗策

| ID | 禁止用途・誤用 | なぜ危険か | v0.1での検出・対抗策 |
|---|---|---|---|
| PU-01 | 本人の意思決定能力、同意能力、認知能力、従順さを採点する | モデルは本人ではなくケア生態系の状態を点検するためのもので、個人評価の妥当性がない | 個人の格付け・能力判定を仕様の適用外にし、出力を本人スコアへ合算しない |
| PU-02 | 診断、治療、退院、入所、ショートステイ、サービス利用、給付の可否を自動決定する | 合成値だけで臨床・生活・法的帰結を正当化できない | AIを最終決定者にせず、現実の介入許可や安全閾値を出力しない |
| PU-03 | 家族・職員・組織の負担軽減を理由に本人の拒否や選好を上書きする | 負担と本人の権利は相殺できず、本人意思の凍結を隠し得る | 主体別結果を分離し、拒否・保留・権利ゲートを単一効用で相殺しない |
| PU-04 | `paused`を安全、中立、同意、現状維持の妥当性と解釈する | 保留中の行動、期間、反復、本人意思の不実現をv0.1はモデル化していない | `pause_consequence_status`と`pause_duration_status`を`not_modeled`とし、保留を成功結果に数えない |
| PU-05 | `all_met=true`を、本人が理解した、不当影響がない、手続きが公正だったことの自動検出結果として使う | 権利ゲートは外生入力であり、CCEが真偽を推定した結果ではない | ゲートの来歴を`synthetic_input`として保持し、不当影響検出器とは主張しない |
| PU-06 | 選択肢喪失率を記録しただけで、選択肢削除を阻止したと説明する | v0.1では選択肢喪失は診断値であり、単独では決定を止めない | 全ゲートを満たした選択肢絞り込みケースを負の機能境界として保存し、限界を明記する |
| PU-07 | 架空の安全性・作業参加・家族負担の表を既定値、臨床的重み、望ましい方向として再利用する | 数値と方向は説明用に置いたもので、実測・合意・規範的根拠がない | `illustrative_non_normative_synthetic_fixture`と表示し、単一得点へ集約しない |
| PU-08 | AIまたは自動化された組織を、本人の委任受任者または本人の代理意思とみなす | 本人の決定権を技術へ移転し、責任と異議申立て先を不明確にする | `delegate_is_ai`を明示的な外生入力として受け、AIへの委任を無効にする。名称から人かAIかを推定しない。ただしv0.1はその申告の真偽を検証できず、誤表示を防ぐ許可機構ではない |
| PU-09 | 合成実験の内部整合性を、人間での効果、安全性、優越性の証拠として提示する | コードと式の一致は外的妥当性を示さない | `synthetic_only`を保持し、人間・臨床で未証明であることを仕様と論文ゲートへ記載する |
| PU-10 | CCEを職員、家族、施設、地域の業績評価や制裁の指標として使う | 記録回避、責任転嫁、弱い立場への負担集中を招き得る | 個人・組織ランキングと単一合成スコアを禁止し、主体別・未測定状態を分離する |

## 3. 公開・レビュー時の確認

- 「モデル内部で確認」と「人間で実証」を分けているか。
- `paused`、`all_met`、`valid`を安全・同意・適法の意味で使っていないか。
- 架空値を臨床推奨値、効果量、閾値として再利用していないか。
- 本人ではなく、本人を取り巻く関係・情報・権限・環境を点検単位としているか。
- AIの出力後に、人間による説明、異議、再検討、最終決定の経路が残っているか。

いずれかに反する利用は、CCE-MVM v0.1の意図された用途外である。検出した場合は出力の利用を止め、用途、責任者、影響を受ける人、非AI代替、訂正方法を記録する。
